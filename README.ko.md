# Agentic Router Proxy

> **초안 — 출시 전 확정 예정.**

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

Agentic Router Proxy는 Claude Code를 위한 난이도 기반 팀 라우터입니다. 플러그인과 로컬 데몬이 각 요청을
읽어 난이도를 가늠한 뒤, 메인 세션이 직접 처리하게 하거나 요청에 맞는 크기의 서브에이전트 팀
(architect, coder, reviewer, tester, ui-designer)을 구성합니다. 각 역할은 모델 × effort "사다리"에
올라가 작업이 어려우면 올라가고 쉬우면 내려오며, 검증을 통과하는 선에서 가장 낮은 비용으로 일을
끝내는 것을 목표로 합니다. CLI와 패키지 이름은 `agentic-router`입니다.

**작동 방식.** Claude Code 플러그인이 훅 이벤트를 `127.0.0.1`의 로컬 데몬으로 전달합니다. 데몬은 각
요청을 판정하고, 계획과 작업 원장을 하나의 로컬 SQLite 파일에 기록한 뒤, 메인 세션("총괄")에게 직접
처리할지 위임할지를 알리는 브리핑을 주입합니다. 위임할 때 총괄은 플러그인이 강제하는 수정 범위와 함께
서브에이전트를 호출하고, 데몬은 각 하위 작업의 빌드·타입체크·린트·테스트를 돌려 비용을 기록하며 역할을
사다리 위에서 조정합니다. 기록·조언용 훅은 실패 시 통과합니다. 데몬이 실행 중이 아니면 Claude Code는
플러그인이 없을 때처럼 동작하고, 그 작업은 "검증 안 됨"으로 기록됩니다. 서브에이전트에 대한 수정 범위
가드는 로컬 파일로 동작하고 오류 시 차단하므로, 서브에이전트는 자기 범위 밖에 쓰지 못합니다.

## 판정

1단계는 규칙만 씁니다 — 임베딩도, 추가 모델 호출도 없습니다. 규칙이 크기를 가늠하지 못할 때에만 2단계로
갑니다. **구독** 모드에서는 총괄이 컨텍스트에 주입된 루브릭으로 판단하고, **API 키** 모드에서는 Sonnet
5.5 judge 호출(effort medium)이 사용자의 API 키로 실행됩니다. 임베딩 기반 유사 사례 검색은 지금은
보류되어 있습니다.

## 위임과 사다리

어떤 레벨을 위임할지는 총괄(메인 세션) 모델에 따라 달라집니다. Opus급 또는 Sonnet 총괄은 **L1**부터,
Haiku 또는 알 수 없는 총괄은 **L2**부터 위임하며, **L0**은 항상 직접 처리합니다. 위임이 이득인 이유는
비싼 총괄이 직접 편집을 그만두기 때문입니다. 직접 대 팀 실측에서 총괄 + Haiku coder 1명은 총괄 혼자보다
약 40% 저렴했습니다(`docs/measurements/` 참고).

역할은 2연속 미스, reject 2회, 또는 총괄이 요청할 때 한 단계 **올라갑니다**. 총괄 요청은 모델이 바뀌지
않으면 슬롯당 1회는 묻지 않고, 그 외에는 사용자 확인 후 적용합니다. 한 슬롯은 최대 3회까지 올리고, 그
뒤에는 사용자에게 묻습니다. 역할은 리뷰어나 테스터가 "easy"로 판정한 결과가 2연속이면 한 단계
**내려갑니다**.

## 설치 (출시 전, 소스에서)

아직 npm에 배포하지 않았습니다. 클론에서 실행하세요:

```
git clone <repo> && cd agentic-router
npm ci
node packages/cli/src/index.ts <command>      # pre-release entry point
```

아래에서 `agentic-router <command>`는 이 진입점을 가리킵니다. 요구사항: **Node 24+**, **Claude Code
≥ 2.1.295**, 그리고 **Windows에서는 Git Bash**.

- `agentic-router init` — Claude Code 플러그인(역할, 훅, 총괄 스킬, 라우터 MCP 도구)과 상태 라인을
  등록하고 구독 모드(기본값)로 설정합니다. API 키 모드는 `init --mode api`를 쓰세요.
- `agentic-router start` — 로컬 데몬(판정 API, 작업 원장, 대시보드)을 백그라운드로 시작합니다.
- `agentic-router doctor` — 설정을 점검하고 문제를 보고합니다.

## 모드

- **구독**(기본, `init`): 플러그인과 로컬 데몬만으로 동작합니다. 프록시가 없고, 어떤 구성요소도 구독
  자격증명을 읽거나 저장하지 않습니다. 트래픽은 Claude Code에서 Anthropic으로 바로 갑니다.
- **API 키**(`init --mode api`): 옵트인 로컬 프록시가 실제 토큰 비용을 집계하고, 로컬 토큰당 하루 $100·
  전체 하루 $300 상한(설정 가능)과 요청별 예산을 적용합니다. 상한을 넘으면 프록시는 새 호출을 429로
  거부하며, 진행 중인 응답은 끊지 않습니다. API 키는 OS 보안 저장소(Windows 자격 증명 관리자 / macOS
  키체인 / Linux libsecret)에만 보관됩니다.
- **직접(direct)**: 프록시에 문제가 생기면 `agentic-router mode direct`로 프록시를 거치지 않고 API
  키로 직접 연결하고, `agentic-router mode proxy`로 되돌립니다.

## 대시보드

`agentic-router dashboard`는 읽기 전용 로컬 웹 대시보드(데몬이 `127.0.0.1`에서 제공)를 엽니다. 요청
타임라인, 요청별 팀·단계·검증 결과, 비용(총괄 대 작업자), KPI, 판정 대 실제 학습 보고서, 자동 해제
패널을 보여 줍니다. 영어·한국어·일본어·중국어 간체를 지원하며, 모든 데이터는 이 기기에만 남습니다.

## 프라이버시

모든 것은 하나의 로컬 SQLite 파일에 저장됩니다. Claude Code 자체 트래픽과, API 키 모드에 한해 2단계
judge의 Anthropic 호출 외에는 아무것도 기기 밖으로 나가지 않습니다. 학습 저장소에는 규칙으로 뽑은
특징값, 결과, 비용, 유사도 같은 수치를 저장하며, 임베딩은 저장하지 않고 프롬프트 원문은 `recordPrompts`를
켰을 때만 저장합니다. 로그와 대시보드는 API 키와 토큰을 가립니다. 어떤 구성요소도 구독 자격증명을 읽거나
저장하지 않습니다.

## 자동 해제 홀드아웃

위임이 여전히 이득인지 확인하기 위해, 위임 레벨 요청의 약 10분의 1을 일부러 총괄이 직접 처리해 홀드아웃
기준선으로 삼습니다. 기본값은 **observe**입니다. 홀드아웃은 돌아가고 대시보드가 비교와 해제 시 결과를
보여 주지만, `autoRelease`를 켜기 전에는 아무것도 전환되지 않습니다. 홀드아웃을 그만두려면
`holdoutRate`를 `0`으로 두거나 `autoRelease`를 끄면 됩니다.

## 한계

- verify는 관련 빌드·타입체크·린트·테스트만 돌리므로, 그 검사가 짚지 못하는 방식으로 틀린 수정은 통과할
  수 있습니다.
- "수용"은 이의가 관측되지 않았다는 뜻(되돌림·재요청·불만 없음)이므로, 성공/수용률은 측정된 승인율이
  아니라 **상한값**입니다.
- 자동 해제는 큰 손실을 막는 브레이크이지 미세 최적화 도구가 아닙니다. 팀이 분명히 더 이상 싸지 않을 때
  넓은 밴드 안에서 그 레벨을 직접 처리로 되돌립니다.
